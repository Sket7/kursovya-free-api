# Промты ИИ-агента для тестов

Папка хранит промты, по которым ИИ-агент (Grok Bot, режим исполнителя) сгенерировал тесты для ветки `mvvm`
в рамках курсовой работы «Разработка мобильного приложения «Rick and Morty»» по дисциплине
«Проектирование мобильных клиент-серверных приложений».

Задание:

> Используя ИИ агента разработайте для своего проекта тесты:
> a. 5 unit тестов для модулей domen слоя (бизнес логики);
> b. 3 интеграционных теста на взаимодействие между слоями data – domen – view;
> c. 2 UI теста.
> Сохраняйте промты и тесты в системе контроля версий.

| Файл | Группа | Тесты | Где лежат |
|---|---|---|---|
| [00-context.md](00-context.md) | общий системный контекст | — | — |
| [01-unit-tests.md](01-unit-tests.md) | a. unit (бизнес-логика) | 5 | `app/src/test` |
| [02-integration-tests.md](02-integration-tests.md) | b. data – domain – view | 3 | `app/src/androidTest/.../integration` |
| [03-ui-tests.md](03-ui-tests.md) | c. UI (Compose) | 2 | `app/src/androidTest/.../ui` |
| [04-fix-iterations.md](04-fix-iterations.md) | уточняющие промты по итогам прогона | — | — |

Порядок работы: агенту передавался общий контекст `00-context.md`, затем промт группы. Результат
проверялся запуском тестов, при необходимости отправлялся уточняющий промт из `04-fix-iterations.md`.
Промты и тесты фиксируются в Git в ветке `tests-ai` (создана от `mvvm`).

Запуск:

```shell
./gradlew testDebugUnitTest            # 5 unit-тестов (JVM)
./gradlew connectedDebugAndroidTest    # 3 интеграционных + 2 UI-теста (эмулятор)
```
