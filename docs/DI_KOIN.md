# Dependency Injection с Koin

Ветка `di-koin` демонстрирует построение приложения через контейнер зависимостей Koin 4.1.0.

## Границы первого блока

- `RickAndMortyApplication` один раз запускает Koin для всего процесса приложения.
- `infrastructureModule` создаёт singleton-экземпляры Retrofit API и Room database.
- `repositoryModule` связывает интерфейсы репозиториев с их реализациями.
- Реализации получают зависимости через конструктор и ничего не знают о способе их создания.
- Сетевой кеш и пользовательские заметки используют общую data-основу из `main`.

## Presentation-модуль

- ViewModel списков объявлены через `viewModel` и получают `CatalogRepository` по интерфейсу.
- ViewModel деталей создаются Koin с runtime-параметром `id` и внедрёнными репозиториями.
- `CommentsViewModel` получает локальный репозиторий заметок из контейнера.
- Жизненный цикл ViewModel остаётся под управлением AndroidX; Koin отвечает только за построение
  графа объектов.
